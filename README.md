## Exercises

### Dictionary Product Lookup

A small interactive shop program that uses a dictionary to store product prices, search for products, and add a new product when it is not found.

It also includes Windows text-to-speech using `win32com.client`.

See [`dictionaries/README.md`](dictionaries/README.md) for the exercise documentation.
